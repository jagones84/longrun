Harness · agent behaviour

Runtimecontinuation rounds
How many times the agent may continue on its own before stopping: it keeps long jobs alive without getting stuck forever.
Verifierapply only if green
After the changes it runs a verification command (e.g. the tests) and applies them only if it passes: if it fails, it reverts.
Best-of-Nmore answers, the best one
Generates N independent answers and keeps the best one: more reliable, but slower and more expensive.
Difficultyadaptive effort
Adapts how many attempts to make based on how hard the task is: few if it is easy, more if it is complex.
Self-evolvingnew skills
Recognizes recurring patterns in your tasks and proposes saving them as reusable skills.
